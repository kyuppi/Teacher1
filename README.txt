【授業時数管理】

■ 使い方
1. index.html をブラウザで開きます。
2. 右上の「⚙」からクラスを追加できます。
   例：1-1、1-2、2-1、3-1 など
3. 「授業時数を入力」でクラス・日付・授業時数を入力します。
4. 「この授業時数を記録する」を押すと保存されます。
5. クラス別集計と記録履歴に自動反映されます。

■ 入力しないもの
授業名・教科名・単元名などの入力欄はありません。

■ データ保存
データはブラウザの localStorage に保存されます。
同じブラウザ・同じ端末で利用する限り、ページを閉じても記録は残ります。

■ 注意
ブラウザのサイトデータを削除すると記録も消える場合があります。
このバージョンはサーバーやデータベースを使用しません。
